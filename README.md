# Python Sales Data Analysis

## Overview
A beginner-friendly sales analysis project using
Python, Pandas, and Matplotlib.

## Features
- Cleans duplicate and missing data
- Calculates revenue and units sold
- Summarizes revenue by product
- Generates a sales chart
- Exports CSV reports

## Tools
- Python
- Pandas
- Matplotlib

## How to Run
Install the libraries:
pip install pandas matplotlib

Run:
python sales_analysis.py

## Project Outputs
- cleaned_sales.csv
- sales_summary.csv
- sales_chart.png
- sales_report.txt

Uses sample data for demonstration only.
